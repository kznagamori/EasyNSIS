# EasyNSIS 評価（テスト）仕様書

## 1. 概要

### 1.1 目的
本文書は、EasyNSISアプリケーションの品質を確保するためのテスト仕様を定義します。

### 1.2 テスト対象
- EasyNSIS バージョン 1.0.0.0
- 対象プラットフォーム: Windows 10/11 (x64)

### 1.3 テスト種別
| 種別 | 説明 |
|------|------|
| 単体テスト | 各サービス・モデル・コンバーターの個別機能テスト |
| 結合テスト | UIを通じた実際の操作による動作確認テスト |

### 1.4 テスト環境
- OS: Windows 10/11 (x64)
- .NET: 10.0
- NSIS: 3.11

---

## 2. テストディレクトリ構成

```
test/
├── TestSpec.md              # 本テスト仕様書
├── UnitTests.csv            # 単体テスト項目リスト
├── IntegrationTests.csv     # 結合テスト項目リスト
├── data/                    # テストデータ
│   ├── sample_app/          # サンプルアプリケーションファイル
│   ├── icons/               # テスト用アイコン
│   └── licenses/            # テスト用ライセンスファイル
└── configs/                 # テスト用設定ファイル
```
